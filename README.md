# 🌾 TerraTech

TerraTech is a smart agricultural marketplace platform that connects farmers, buyers, and equipment owners in a single ecosystem. The platform enables farmers to sell agricultural products directly to customers while also providing access to farm equipment rentals at affordable prices.

---

## 🚀 Features

### 🌾 Farmer Marketplace
- Direct farmer-to-buyer sales
- Product listing and management
- Product categories and search
- Shopping cart functionality
- Order management
- Product ratings and reviews

### 🚜 Equipment Rental
- List agricultural machinery for rent
- Browse available equipment
- Rental booking system
- Equipment availability tracking
- Rental history management

### 👤 Authentication
- User registration and login
- Demo authentication support
- Role-based access control
- Secure user management

### 📊 Dashboard
- Farmer dashboard
- Equipment owner dashboard
- Order tracking
- Revenue insights

### 🔍 Search & Filtering
- Search products
- Search equipment
- Category filters
- Location-based discovery

## 🎯 Problem Statement

Small-scale farmers often face:

- Dependence on middlemen
- Reduced profit margins
- Limited market access
- Expensive agricultural machinery

TerraTech solves these challenges by creating a digital platform where farmers can directly sell products and rent equipment whenever needed.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Pradxpk-88/TerraTech.git
```

### Navigate to Project

```bash
cd TerraTech
```

### Install Dependencies

```bash
npm install
```

### Start Backend

```bash
npm start
```

### Start Frontend

```bash
npm run dev
```
